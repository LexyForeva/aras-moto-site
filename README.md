# Aras Reklam Moto Aksesuar

Motosiklet aksesuarları e-ticaret sitesi

## Özellikler

- 🏍️ 20+ marka desteği (BMW, Honda, Yamaha, Kawasaki, vb.)
- 📦 Ürün yönetim sistemi
- 🔐 2FA güvenlik (Email)
- 🛒 Shopier, Trendyol, Hepsiburada entegrasyonu
- 📱 Mobil uyumlu tasarım
- 🔍 Gelişmiş arama ve filtreleme

## Kurulum

```bash
npm install
node server.js
```

## Environment Variables

```
SESSION_SECRET=your-secret-key
ADMIN_USERNAME=arasadmin
ADMIN_PASSWORD=your-password
EMAIL_USER=your-email@gmail.com
EMAIL_PASS=your-app-password
PORT=3000
```

## Admin Panel

- URL: `/admin`
- Kullanıcı: arasadmin
- 2FA ile giriş

## Teknolojiler

- Node.js + Express
- Vanilla JavaScript
- Email 2FA
- Session yönetimi
- Bcrypt şifreleme
